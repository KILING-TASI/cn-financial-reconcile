# 美的2025年报：一个现金覆盖问题的完整流程

问题：选定2025年合并经营现金流减选定资本开支，能否覆盖该年宣告分红？截止2026-10-09。此案例完整覆盖问题定义、官方原件取得、字节摘要、主体/年度/单位/金额短引句核对、计算、自然语言结果与阻断结论。不是完整公司估值、未来分红承诺或投资建议。

2026-10-10本轮从登记深交所URL重新取得PDF，原始SHA256与既有选定原件一致；六项绑定页短引句、单位及数值token核对通过。经营现金流减选定资本开支422.04041亿元，宣告分红覆盖约1.3042倍；合并现金不等于母公司可分配现金。没有自动核验“该版本最新”、会计分类或全部正文；实际支付金额与宣告金额分别观察。

在完整源码目录安装可选PDF组件，然后用新目录复现：

```powershell
python -m pip install ".[pdf]"
python tools/reproduce_midea_case.py --download --out-dir local-data/midea-first
```

`--download`仅显式请求登记原URL一次；不更换镜像或原版本。已合法取得相同原件时，可改用`--pdf 自己的PDF路径`。未知摘要、缺组件、原页不匹配都会停止；旧目录拒绝。原PDF只保存在自己的输出目录，不随仓库或Release再分发。

本目录input.json是移除本地PDF路径的公开投影，不能据此重新认证原页。result.json及report保留本轮实际核验结果，receipt.json记录公开文件摘要。直接用input.json重新计算时只得到“声明证据”状态；完整复现须提供/取得同一原件。短引句只为字段核对，公告与数据权利不随代码MIT许可转移。
